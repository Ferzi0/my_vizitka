# Аналитика: как включить

По умолчанию аналитика **выключена**: сайт ничего не грузит с чужих адресов, cookie нет.
В `js/main.js` есть нейтральная функция `track(имя)`. Пока сервис не подключён, она ничего не делает.

## Какие события отправляются

Отправляется только имя события. Данных из формы, имени, контакта и текста среди них нет.

| Событие | Когда |
|---|---|
| `cta_discuss` | клик по любой кнопке или ссылке «Обсудить проект» (`href="#contact"`) |
| `form_success` | заявка ушла через `send.php` |
| `form_fallback` | сервер недоступен, открыто письмо через mailto: |
| `contact_email` | клик по ссылке на почту |
| `contact_email_copy` | адрес почты скопирован кнопкой |
| `qr_socials` | клик по плавающему QR «все соцсети» |
| `qr_hide` / `qr_show` | QR свернули / вернули язычком под шапкой |
| `contact_telegram` | клик по ссылке на Telegram |
| `contact_bot` | клик по кнопке «Заявка через Telegram-бота» |

## Что выбрать

Все три варианта работают без cookie и без персональных данных. Баннер согласия на cookie для них не нужен.

- **Plausible** — облачный, платный, самый простой. Свои события видны в отчёте после того, как их добавят как цели (Goals) в настройках сайта.
- **GoatCounter** — облачный, бесплатный для некоммерческих сайтов, есть self-host.
- **Umami** — бесплатный, ставится на свой сервер (self-host) или в облако Umami.

## Как включить (3 шага)

1. **index.html**, блок-комментарий после `<script src="js/main.js">`. Вынесите из комментария **одну** строку и подставьте свои данные:
   - Plausible: `data-domain` — домен сайта;
   - GoatCounter: `ИМЯ` — код сайта в GoatCounter;
   - Umami: `АДРЕС-UMAMI` — адрес вашего сервера Umami, `data-website-id` — идентификатор сайта.
2. **_headers**, строка CSP для `/*`. Допишите домен сервиса в `script-src` и `connect-src`, готовые пары есть в комментарии в начале файла:
   - Plausible: `script-src 'self' https://plausible.io` и `connect-src 'self' https://plausible.io`;
   - GoatCounter: `script-src 'self' https://gc.zgo.at` и `connect-src 'self' https://ИМЯ.goatcounter.com`, плюс `img-src 'self' https://ИМЯ.goatcounter.com` (запасной способ отправки — картинка);
   - Umami: `script-src 'self' https://АДРЕС-UMAMI` и `connect-src 'self' https://АДРЕС-UMAMI`.

   На Apache или nginx те же правки нужно внести в CSP в конфиге сервера: `_headers` там не действует.
3. **privacy.html**, пункт «Аналитика». Замените заглушку названием сервиса и добавьте: «без cookie, без персональных данных».

`js/main.js` менять не нужно: `track()` сама найдёт подключённый сервис (`window.plausible`, `window.umami` или `window.goatcounter`).

Проверка: откройте сайт с открытой консолью. Ошибок CSP быть не должно, а в панели «Сеть» после клика по «Обсудить проект» появится запрос к сервису.
