### Решение по шрифту (важно)
- **Bebas Neue не содержит кириллицы.** Проверено реально: CSS Google Fonts отдаёт для Bebas Neue только сабсеты `latin` и `latin-ext`; в полном TTF из google/fonts — 0 из 64 букв А–я, нет и ₽.
- Сравнены по скриншотам кириллические узкие гротески: Oswald, Sofia Sans Extra Condensed, Alumni Sans, Fira Sans Extra Condensed, Roboto Condensed (+ проверены Anton, League Gothic, Antonio, Big Shoulders — у них кириллицы нет). Выбран **Sofia Sans Extra Condensed 700**: ближе всего к Bebas по ширине, весу штриха и прямоугольным овалам; Oswald шире, а его прописные на 16 % выше.
- Семейство **«Ferz Display»** из двух файлов через `unicode-range`: латиница/цифры/пунктуация (FERZ, 10 900, PYTHON) → Bebas Neue; кириллица → Sofia Sans Extra Condensed с `size-adjust: 107%` (высота прописных подогнана к Bebas). Текст — **Onest** (вариативный 400–700). Всего 3 файла woff2, self-host, `font-display: swap`: 11,1 + 6,6 + 24,3 КБ = 42 КБ. Лицензии OFL 1.1 (без Reserved Font Name) лежат в `assets/fonts/`. Знак ₽ в крупных ценах набирается текстовым шрифтом (его нет ни в Bebas, ни в Sofia) — оформлено как отдельный элемент `.rub`.

### Палитра и сезоны
- Все цвета выводятся из **5 чисел** блока `:root[data-season="autumn"]` (оттенок/насыщенность бордо и акцента, подтон бумаги) в OKLCH → шкалы: бордо 11 ступеней (50…950), акцент 7, нейтрали 13 → смысловые токены светлой/тёмной темы и винных блоков (`.scope-wine`). Компоненты используют только смысловые токены. В CSS закомментированы примеры `winter` / `spring` / `summer`; инструкция «как менять» — в комментарии в начале `css/main.css`.
- 60-30-10: слоновая кость с тёплым подтоном (60 %), бордо (30 %: заголовки-акценты, винные разделы, доска), один акцент (10 %: главная кнопка, корона, отметки ходов).
- **Акцент — старое золото / латунь** (`oklch(0.81 0.118 78)` ≈ #ebb763). Почему: тёплая пара к бордо (вино и латунь — классический шахматный комплект, осенняя листва), высокая светлота даёт сильный контраст на винном фоне и как заливка под тёмным текстом. На светлом фоне золото **никогда не используется для текста**: только заливка (с бордовой границей 10,9:1) и тёмная бронза `accent-800` для мелких подписей (6,2–7,3:1).
- Тёмная тема: очень тёмное вино `oklch(0.155 0.024 14)` (#150809), свечение бордо за ферзём и в «Как работаю». Нейтрали без чистого чёрного/белого.
