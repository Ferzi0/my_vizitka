# Сайт-визитка: Эдуард Торгашов (Ferz)

Одностраничный сайт разработчика сайтов, Telegram-ботов и веб-сервисов. Статические HTML, CSS и немного JavaScript без фреймворков и сборки. Тема «ход ферзя»: разделы страницы — ходы, ферзь движется по доске вместе с прокруткой. Палитра осенняя, бордовая, меняется по сезонам.

## Запуск локально

```bash
cd ferz-site
python3 -m http.server 8000
# http://localhost:8000
```

Через npm (удобно, чтобы открыть сайт на телефоне):

```bash
npm start
```

Сервер слушает все сетевые интерфейсы на порту 8080. Узнайте IP компьютера (`ipconfig getifaddr en0` на macOS), телефон должен быть в той же Wi-Fi сети: откройте `http://IP-компьютера:8080`. Остановка: Ctrl+C. `send.php` на таком сервере не работает, поэтому форма уходит через почтовую программу.

Страницы открываются и двойным кликом (`file://`), но шрифты браузер при этом может не подгрузить, и форма сразу пойдёт через почтовую программу.

## Структура

```
index.html, privacy.html     страницы
css/main.css                 дизайн-система (токены, сезоны) и стили; css/privacy.css
js/theme-init.js, js/main.js тема без мигания; прогрессия, меню, форма, аналитика-слот
send.php                     приём заявок с формы на хостинге с PHP
send.config.example.php      образец настроек (копия send.config.php создаётся на сервере)
.htaccess, _headers          заголовки безопасности: Apache и Netlify/Cloudflare Pages
assets/                      иконки, og-image.jpg, шрифты (woff2 + лицензии OFL)
tools/                       set-domain.sh, package.sh, minify.sh
ANALYTICS.md                 как подключить приватную аналитику
STATUS.md                    история этапов, проверки, долг (на сервер не выкладывать)
```

## Что заполнить перед публикацией

Заглушки на сайте помечены `[ЗАПОЛНИТЬ]` (пунктирная плашка).

1. **Почта** (`hello@example.com`): контакты, подвал, форма, `js/main.js`, `privacy.html`.
2. **Telegram:** ник вместо `@example_username` и ссылка на бота `t.me/example_bot`.
3. **GitHub** и **сертификаты:** ссылки в блоке стека.
4. **FAQ:** ответы про предоплату и про права на код. Условия назвать нужно вам.
5. **Домен:** `sh tools/set-domain.sh ваш-домен.ru` подставит его в canonical, Open Graph, JSON-LD, sitemap и robots. Сначала можно добавить `--dry-run`.
6. **Фото:** добавьте `<img class="portrait__img" ...>` в `.portrait__frame` (подсказка в разметке). Монограмма «ЭТ» скроется сама.
7. **Политика конфиденциальности:** проверьте обязательства в `privacy.html` (хранение, удаление, аналитика) и подтвердите их фактическими настройками.

## Форма заявок

Работает в двух слоях:
- на хостинге с PHP форма отправляет заявку на `send.php` (проверка Origin, honeypot, лимит 3 заявки за 10 минут с одного адреса, очистка полей, защита от подмены заголовков письма);
- если PHP недоступен (Netlify, GitHub Pages, ошибка сети), форма сама открывает письмо в почтовой программе (`mailto:`).

Настройка на сервере:
1. Скопируйте `send.config.example.php` в `send.config.php` и заполните почту получателя и случайную соль.
2. Если сайт стоит за прокси или CDN, заполните `allowed_hosts` (иначе все заявки получат 403).
3. Проверьте, что `send.config.php` не отдаётся по HTTP (`.htaccess` закрывает его; для nginx нужны правила, они есть в `STATUS.md`).

Не проверялась реальная доставка письма (SPF/DKIM, спам). После публикации отправьте тестовую заявку.

## Выкладка

```bash
sh tools/package.sh            # release/ferz-site/ и zip: Apache + PHP, обычный хостинг
sh tools/package.sh --min      # то же, но CSS и JS минифицированы (нужен Node.js)
sh tools/package.sh --static   # для Netlify / Cloudflare Pages / хостинга без PHP
```

В пакет входят только файлы сайта. Не выкладывайте `.git`, `STATUS.md`, `ANALYTICS.md`, `tools/`, `send.config.example.php`.

Если после выкладки на Apache весь сайт отдаёт ошибку 500, хостинг ограничивает директивы в `.htaccess`. Начало файла описывает, что удалить в каждом случае по тексту из error_log.

Рекомендации хостингу: HTTPS (потом раскомментировать HSTS в `.htaccess`), gzip или brotli включены. Для nginx готовые строки заголовков лежат в `STATUS.md`.

## Как менять

**Цвета и сезоны.** Блок `[data-season="autumn"]` в начале `css/main.css`: цвета строятся из нескольких чисел. Там же закомментированные примеры зимы, весны и лета. Для нового сезона поменяйте этот блок, а также `favicon.svg`, `apple-touch-icon.png` и `og-image.jpg` вручную: они пока не следуют за палитрой.

**Тексты и цены.** `index.html`, по порядку разделов: услуги и цены, как работаю, работы, стек, вопросы, контакт.

**Аналитика.** Выкл. по умолчанию. Выбор сервиса и строки для подключения: `ANALYTICS.md`.

## Что проверено, а что нет

Проверено в Chromium: консоль и CSP, контраст, axe, клавиатура, без JS, reduced-motion, крупный шрифт, Lighthouse Mobile 100/100/100/100, форма с PHP 8.3 и системный Apache 2.4. Подробности и числа в `STATUS.md`.

Не проверялось: Safari, iOS, Firefox, скринридеры, PHP 7.4, nginx, brotli, настоящий HTTPS, реальная доставка писем, открытие `mailto:` в почтовых программах.
